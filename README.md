# Shardfall Online
Your Shardfall game (`public/index.html`) with online 1v1 through a small Node.js + Socket.IO relay server.

## Run locally
    npm install
    npm start
Open http://localhost:3000 in two windows. In each: ONLINE -> pick a fighter -> one player presses "Host game", the other types the code and presses "Join".

## Deploy (Render Web Service)
Build Command `npm install` | Start Command `npm start` | Health check `/health` | Region: Singapore (closest to Australia)
